# Slack 메시지의 종류와 빈도

`scripts/tocom/report.py`가 보내는 메시지다. 예시는 `results/tocom-cl-main-v3/reports/events.jsonl`에 남은 실제 메시지에서 가져왔다(123개 실행, 30시간 18분, 메시지 20건, 전달 실패 0건).

| 메시지 | 보내는 것 | 언제 | 건수 |
|---|---|---|---|
| 🚀 시작 | `kickoff` | 대기열 시작 직전. 전달되지 않으면 시작하지 않는다 | 1 |
| 📈 진행 | `watch` | 2시간마다(`--digest-hours`) | 실험 시간 ÷ 2 |
| 📊 seed 끝남 | `finish` | seed 하나의 실행이 모두 끝났을 때. `kickoff --seed-tables`를 준 경우만 | seed 수 |
| 🏁 끝남 | `finish` | 마지막 실행이 끝났을 때 | 1 |
| ❌ 실패 | `finish` | 실행이 실패한 즉시. 어디까지 했는지와 로그의 마지막 줄 | 생길 때 |
| 🛑 멈춤 | `watch` | 실행의 기록이 30분 넘게 늘지 않을 때(예상 100분 초과 실행은 예상의 30%). 멈춤 한 번에 한 건 | 생길 때 |
| ⛔ 대기열 멈춤 | `watch` | 남은 실행이 있는데 도는 것이 10분째 없을 때. 이 뒤 watch는 끝난다 | 생길 때 |
| 자유 문장 | `say` | 사전 점검 결과, 작업자가 연속 2회 실패로 멈출 때 | 생길 때 |
| ▶️ 시작, ✅ 완료 | `start`, `finish` | 실행마다. `kickoff --per-run`을 준 경우만. 짧은 대기열용 | 실행 수 × 2 |

"예상 초과"는 따로 알리지 않는다. 진행 요약의 실행 중 줄에 ⚠️로 표시된다(예상 시간의 1.5배에 10분을 더 넘긴 경우).

## 시작

```
🚀 *tocom-cl-main-v3 시작* · 실행 123개
압축 없이 학습 27 · plug-in으로 줄여 학습 84 · 자체 압축으로 학습 12 (방법 9개 × seed 1993·1994·1995)
동시에 6개 · 예상 16시간 45분 → 22:07쯤 끝남
보고: 2시간마다 진행 요약, seed 하나가 끝나면 요약표. 실패와 멈춤은 바로, 끝나면 전체 요약
W&B: https://wandb.ai/laymond1/tocom-plugin-cl
```

이 실험은 실제로 30시간 18분 걸렸다. 시작 시점의 예상은 이전 실험의 시간에서 나온 것이라 설정이 바뀌면 크게 틀릴 수 있고, 같은 설정의 실행이 끝나면서 맞아 간다. 이 실험의 실측으로 `estimates.json`을 다시 만들면 같은 대기열의 시작 예상이 30시간 21분으로 나온다.

## 진행 요약

```
📈 *tocom-cl-main-v3 진행* · 8시간 03분 경과
진행: 완료 32 · 실행 중 6 · 대기 85 · 실패 0 · 전체 예상 종료 10/13 09:07
지난 2시간 00분 동안 끝난 실행 8개 · 최종 class-IL 평균(%), none은 같은 방법과 seed를 압축 없이 학습한 실행
method   train   seed  acc none
ER       ToMe 16 1993 26.9 27.4
LwF-MC   ToMe 16 1993 41.2 43.1
CODA     EViT 8  1993 66.7 69.4
...
• GPU 1 · CODA-Prompt · ToMe 16 · seed 1993 · 1시간 04분 경과(예상 48분) · 태스크 8 에포크 16
• GPU 1 · SD-LoRA · ToMe 16 · seed 1993 · 48분 경과(예상 24분) · 태스크 7 에포크 5 · ⚠️ 예상 초과
...
```

표의 한 줄은 40자를 넘지 않는다. 휴대폰에서 줄이 꺾이지 않게 하기 위해서다. 표에 넣는 숫자는 실행당 하나(`acc`)와 그 기준(`none`)뿐이다. 보정 이득은 seed 요약표와 전체 요약에 있다.

## seed 요약표와 전체 요약

```
📊 *seed 1993 끝남* · 41개 중 완료 41, 실패 0 · 최종 정확도(%)
압축 없이 학습 → 추론 16 (base: 학습한 그대로, 보정 끔>켬)
method   base ToMe 16   EViT 16
ER       27.4 27.3>27.4 23.8>23.8
CODA     69.4 64.4>66.2 53.9>59.1
...
```

전체 요약(🏁)은 같은 표를 seed 평균으로 만들고, 완료와 실패 수, 총 시간, 결과 위치, W&B 집계 실행 주소를 덧붙인다. 이때 모든 조건의 최종 정확도를 담은 `reports/final_grid.csv`도 쓴다.

## 문구를 바꿀 때

메시지는 한 건만 읽고도 상황을 알 수 있어야 한다. 첫 줄에 무엇이 일어났는지, 둘째 줄에 진행 수와 예상 종료를 둔다. 숫자는 비교 대상과 함께 적는다. 바꾼 뒤에는 `tests/test_tocom_reporting.py`를 돌리고, 임시 폴더의 대기열에서 `--dry-run`으로 출력을 눈으로 확인한다.
